
# ExohoodSwap - Permanently Discontinued

> ⚠️ **PROJECT PERMANENTLY DISCONTINUED**
>
> Exohood Labs Inc. has permanently discontinued the original ExohoodSwap project.
>
> **This repository is no longer maintained, developed, supported, or open to external contributions.**
>
> The cryptocurrency exchange and fiat-to-crypto integration services originally proposed through this project are no longer available under this initiative.

> **ExohoodSwap must not be confused with Exoswap, the separate decentralized exchange application currently developed by Exohood Labs.**
>
> This repository is retained exclusively for historical, educational, and archival purposes.

## Historical Project Overview

ExohoodSwap was originally conceived as a cryptocurrency exchange integration project.

The initiative explored software functionality that would allow users to exchange digital assets and access cryptocurrency purchases through third-party fiat payment providers.

The original project description stated:

> ExohoodSwap allows your users to swap cryptocurrencies, buy any cryptocurrency using fiat.

This description reflects the historical objectives of the project and does not represent currently available functionality.

## Historical Features

The original development concept explored:

- Cryptocurrency swap integrations.
- Digital asset exchange functionality.
- Third-party liquidity access.
- Fiat-to-crypto payment integrations.
- Cryptocurrency purchase interfaces.
- Blockchain application connectivity.

These features were part of the project's original scope.

They should not be interpreted as evidence that every proposed capability was implemented, deployed, or commercially released.

## Development Status

**ExohoodSwap has been permanently discontinued.**

Exohood Labs no longer provides:

- Cryptocurrency exchange services through this project.
- Fiat-to-crypto payment integrations.
- API maintenance or integration assistance.

- Technical support.
- External development collaboration.

No future relaunch is planned under this initiative.

## Relationship With Exoswap

**Exoswap remains an active and separately maintained decentralized exchange application.**

The current Exoswap platform provides non custodial cryptocurrency swaps through supported blockchain networks, compatible Web3 wallets, and external decentralized liquidity aggregation.

Exoswap is developed separately from this discontinued ExohoodSwap repository.

The current platform does not operate the former ExohoodSwap fiat-to-crypto service.

**Official Exoswap Application:** https://exohood.app

The discontinuation of ExohoodSwap does not affect Exoswap's ongoing development or its public community collaboration initiatives.
